# AIV releases

Download page and release archive of **AIV, Astonishing Image Viewer**, the image viewer and editor for Android by Rocco Casadei, a.k.a. Roccobot.

- Download page: <https://roccobot.github.io/AIV/>
- Latest version: [releases/latest](https://github.com/Roccobot/AIV-releases/releases/latest)
- Privacy policy: <https://roccobot.github.io/AIV/privacy.html>

Each release carries the APK of AIV, which updates itself from here, and the APK of AIV Play, the variant published on Google Play. The source code is not public: this repository holds only the builds.

Questions and bug reports go in [Issues](https://github.com/Roccobot/AIV-releases/issues).
